## 第 1 页｜封面

- 主标题：**Xipoo 吸噗**
- 副标题：西浦人的校园生活一站式小助手
- 要点：
  - 微信小程序，扫码即用，无需下载
  - 覆盖 XJTLU 太仓（TC）与苏州工业园区（SIP）双校区
- 备注：名称「吸噗」取自 Xipoo 音译，活泼好记；默认主题色为莫奈·睡莲紫 `#7c83c7`，封面可用该色系。

## 第 2 页｜痛点：西浦学生的日常烦恼

- 要点：
  - 课表难录：手动敲课表太麻烦，截图课表散落在相册
  - 约人靠吼：想约同学吃饭/自习，挨个问「你几点有空」
  - 活动分散：各学院活动藏在十几个公众号里，经常错过报名
  - 隐私顾虑：日程想分享又怕暴露太多
- 备注：面向学生的真实场景切入，引起共鸣。

## 第 3 页｜产品定位

- 要点：
  - 一句话：**管课表、约时间、找活动，一个小程序全搞定**
  - 目标用户：西交利物浦大学在校学生（双校区）
  - 产品形态：微信小程序 + Web 管理后台
  - 设计语言：中英文双语切换，适配国际化校园
- 备注：不做陌生人社交，只服务现实认识的同学与真实校园活动。

## 第 4 页｜核心功能总览

- 要点（四大模块）：
  - 📅 **智能日程**：课表日/周/月视图，AI 拍照识别录入
  - 🤝 **日程共享**：分级授权给好友，一键算共同空闲
  - 🎉 **校园活动**：热门推荐、活动方门面、在线报名
  - 🐰 **AI 助手**：右下角兔子助手，随时对话
- 备注：四大模块对应小程序底部四个 Tab：日程 / 活动 / 共享 / 我的。

## 第 5 页｜功能一：智能日程

- 要点：
  - 日 / 周 / 月三种视图，月视图为完整日历网格
  - **AI 课表录入**：拍一张课表截图，云端 OCR + AI 自动识别课程、时间、地点，秒级入库
  - 识别记录可回看「标注核验图」，识别结果有据可查
  - 学期管理、课程详情、自定义日程
- 备注：AI 识别链路：小程序拍照 → 云函数提交 → OCR 服务识别 → 回传标注图持久化到云存储。

## 第 6 页｜功能二：日程共享中心

- 要点：
  - 只和现实认识的同学共享，**不帮用户认识陌生人**
  - 四级权限精细控制：完全不可见 / 仅忙闲 / 可见标题 / 可见详情（含地点）
  - 可设共享有效期，随时收回授权
  - **共同空闲计算**：选好友 + 日期 + 时间段，自动算出大家都空的时间
  - 时间小组：常用多人组合一键带入
  - 添加方式：微信邀请卡片直达 / Xipoo ID 精确搜索
- 备注：解决「约时间」高频痛点，权限模型是差异化亮点。

## 第 7 页｜功能三：校园活动

- 要点：
  - 发现页：🔥 热门活动顶部轮播 + ⭐ 推荐活动双列瀑布流
  - 活动详情：时间地点、中英文介绍、在线报名
  - **活动方门面**：每个学院/社团有品牌主页——Logo、横幅、品牌故事、现场图集、联系方式
  - 订阅喜欢的发布方，新活动不错过
  - 覆盖 TC / SIP 两校区，已接入 10 个学院级活动方（芯片学院、PAI空间、浦创汇、物联网学院、智能机器人学院、智造生态学院、产金融合学院、人工智能与先进计算学院、创新工场、太仓文体广旅）
- 备注：活动不再是散落的公众号推文，而是结构化、可订阅、可报名的信息。

## 第 8 页｜功能四：AI 能力贯穿全产品

- 要点：
  - **AI 课表识别**（用户端）：拍照 → 课程自动入库
  - **AI 海报录入**（管理端）：运营上传活动海报，豆包视觉大模型自动提取标题/时间/地点/简介，校对后一键发布，录一条活动从 10 分钟缩到 1 分钟
  - **兔子 AI 助手**：常驻右下角，随问随答
- 备注：AI 不是噱头，分别在「录入课表」和「运营录入活动」两个最繁琐的环节替代人力。

## 第 9 页｜设计亮点

- 要点：
  - **莫奈·印象派主题**：默认「睡莲紫」，另有日出橙、鸢尾蓝紫等艺术色系
  - 10 套预设主题 + 自定义取色，全局一键换肤
  - 深色模式支持
  - 水彩光斑渐变背景、卡片「浮于水面」的视觉语言
- 备注：主题引擎为自研运行时换肤，全页面 CSS 变量驱动。

## 第 10 页｜安全与隐私

- 要点：
  - 全部用户内容（文本 + 图片）接入微信官方内容安全 API，违规即时拦截
  - 日程共享分级授权，私密日程任何级别都不外传
  - 黑名单/屏蔽、举报通道、反馈中心闭环
  - 手机号 + 短信验证码登录，账户体系合规
- 备注：内容安全覆盖 6 个云函数、18 个检测点，通过微信审核整改验证。

## 第 11 页｜运营后盾：Web 管理后台

- 要点：
  - 活动方管理：品牌资料、Logo/横幅上传、启用/禁用、校区归类
  - 活动管理：新建/编辑/删除、热门与推荐位运营配置
  - **AI 一键录入**：海报拍照即发布
  - 举报 / 用户反馈处理工作台
  - 数据仪表盘：各活动方活动量一目了然
- 备注：面向运营同学，证明产品可持续运营、内容可持续生产。

## 第 12 页｜技术架构

- 要点：
  - 前端：微信小程序原生框架，自定义组件 + 分包加载
  - 后端：腾讯云开发 CloudBase（8 个云函数 + 云数据库 + 云存储 + 静态托管）
  - AI：OCR 课表识别服务（云托管）+ 豆包视觉大模型
  - 工程化：分支协作规范、Node 自动化测试 14+ 项、内容安全专项测试
- 备注：Serverless 架构，零服务器运维成本，按需弹性伸缩。

## 第 13 页｜团队

- 要点：
  - 5 人模块化分工：日程 / 匹配 / 活动 / 好友 / 我的 五大板块
  - 规范协作：feature 分支 → Pull Request → 联调 → 稳定分支
  - 每个 PR 需说明页面、API、云函数、数据库变更
- 备注：可按实际情况替换为真实成员照片与姓名。

## 第 14 页｜愿景与规划

- 要点：
  - 短期：完善活动报名提醒、共享二维码邀请
  - 中期：活动签到、日历订阅导出、更多学院入驻
  - 长期：成为西浦校园生活的默认入口
- 备注：规划项可按团队真实 roadmap 调整。
