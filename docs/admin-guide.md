## 📊 功能概览

登录后有五个标签页：

### 1. 活动仪表盘
- 按**发布方分类**展示活动卡片（数据实时来自发布方管理，新建发布方后自动出现）
- 每张卡片显示：该发布方近期活动时间线 + 活动总数 + 即将举办数
- **方便分配任务**：一眼看出每个活动方什么时间发布了哪些活动

### 2. 活动管理
- 活动列表表格，支持**按发布方和日期筛选**（发布方下拉为动态数据）
- 新建 / 编辑 / 删除活动
- 新建活动表单包含：中英文标题、日期时间、地点、封面图、标签等完整字段

### 3. ✨ AI 录入（海报识图 + 语音录入）
- 进入 AI 录入先**选择活动方**（默认选中当前账号绑定的活动方）：未选择时无法开始识别；选定后自动用发布方配置补全空缺的主办方/地点字段（不覆盖 AI 已识别的内容），文字海报第一款主题使用发布方品牌色，「填入活动表单」时自动带出该发布方
- **上传海报**（点击或拖拽，JPG / PNG / WebP ≤ 15MB，大图自动压缩后经云存储传输），混元视觉模型（`hy3-preview`，经 `@cloudbase/node-sdk` 在云函数内调用）自动提取标题、日期时间、地点、主办方、简介、标签、分类等字段
- **语音录入**：点麦克风直接口述活动信息（浏览器语音识别转文字，可手动修改；不支持的浏览器可直接打字/粘贴），混元大模型（`hy3-preview`，经 `@cloudbase/node-sdk` 在云函数内调用）把口语整理成同一套结构化字段，「明天/下周三」等相对日期自动换算
- 四步流程：**上传/语音 → AI 识别/整理 → 校对确认 → 完成**
- 校对页所有字段可手动修正，也可在**「💬 改稿」框直接说修改意见**（如「时间改到下午三点」），混元会更新全部相关字段（含英文翻译同步）；确认后「填入活动表单」自动预填活动表单，选好发布方保存即可
- 校对页对**必填项（中文标题、日期）实时标红提示**，缺失时无法填入表单；「✍️ 润色简介」可把口语化简介改写为宣传稿文案（中英双语）
- 识别耗时约 15~60 秒属正常（图片经云存储中转，绕开 HTTP 触发器约 100KB 的请求体上限）
- 海报识图依赖 activityAdmin 云函数环境变量 `ARK_API_KEY`（火山方舟 API Key）和 `ARK_MODEL`（当前为 `doubao-seed-2-0-pro-260215`），配置方法见 `docs/deployment-workflow.md`；语音整理/改稿/润色走 CloudBase 混元资源包，无需额外 Key

### 3.1 🎨 文字海报生成
- 没有宣传图时，校对页点「生成文字海报」（或活动编辑弹窗封面链接旁的同名按钮），本地 Canvas 即时渲染 750×1000 文字海报：标题、日期时间、地点、主办方、标签胶囊 + 渐变背景，可「换一款样式」切换主题（编辑弹窗里第一款会用发布方品牌色）
- 「填入活动表单」时自动把海报上传云存储（`ai-import/posters/`）并设为封面；活动编辑弹窗里则直接覆盖封面链接（已有封面会先确认）
- 「⬇ 下载海报」可保存 JPG 到本地，直接发朋友圈/群
- 纯前端生成、免费秒出、中英文不会出错字，不消耗 AI 额度

### 4. 发布方
- 顶部统计卡片：发布方总数 / 启用 / 禁用 / 活动总数
- 支持**搜索**、**新建发布方**（仅总管理员）
- 每个发布方卡片显示活动统计（总 / 进行中 / 即将 / 已结束），可**编辑**、**启用/禁用**、**删除**（仅总管理员，有关联活动时不可删）
- 编辑窗口涵盖小程序活动方主页展示的全部字段：
  - 基本信息：key、中英文名、图标、认证、启用
  - 品牌视觉：Logo、**背景横幅 coverUrl**、主色、强调色（颜色选择器）
  - 展示文案：一句话简介、**活动方介绍**、地点、成立标签（中英双语）
  - 品牌故事：故事标题与正文（中英双语）
  - 内容与联系：内容标签、联系方式、现场图集
  - 运营配置（仅总管理员）：发现页标签、配额、排序权重、置顶、可见性

### 5. 举报/反馈
- 查看和处理用户举报、用户反馈（待处理 / 已解决 / 已忽略）
- 处理时可填写管理备注（adminNote），用户可在小程序「反馈中心 → 我的反馈」看到处理状态和官方回复
- 反馈附带的图片以缩略图展示，点击可看大图

## ➕ 如何添加新成员账号

目前只能由管理员在代码中手动添加。步骤：

1. 打开 `cloudfunctions/activityAdmin/accounts.js`
2. 在数组中添加新对象：
```js
{
  username: '新账号名',
  password: '密码',
  publisherKey: 'chips',   // 选一个：chips / badminton / xec / campus / library / career
  displayName: '显示名称'
}
```
3. 微信开发者工具 → `cloudfunctions` → 右键 `activityAdmin` → **上传并部署：云端安装依赖**

## 🚀 部署方式

后台网页部署在**云开发静态网站托管**上：

1. 将 `admin/web/` 目录下的文件上传到云开发静态托管
2. 或者通过 CloudBase CLI：
```bash
tcb hosting deploy admin/web/ -e prod-d3ged1wr3c6f6ce74
```

即可通过上述链接访问。
